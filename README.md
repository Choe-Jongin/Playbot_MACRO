# 카카오톡 플레이봇 강화 매크로

카카오톡 채팅방에서 **플레이봇 강화 명령(`/강화`)을 자동으로 반복 실행**하고,
강화 결과를 분석하여 **목표단계 도달 / 통계**를 수집하는 매크로입니다.

본 매크로는 OCR을 사용하지 않으며,
**채팅 영역 화면 변화 감지 + 클립보드 텍스트 복사 방식**으로 안정적으로 동작합니다.

응용프로그램(exe) 형태로 제공되지 않습니다.

기본적인 파이썬 사용 방법을 숙지하셔야 합니다.

pip를 통해 라이브러리를 추가 설치가 필요할 수 있습니다.

---

## 🚀 가장 중요한 사용법 (반드시 숙지)

### ▶ 매크로 조작 키

F8 : 강화 매크로 시작  
F9 : 강화 매크로 즉시 중지  

⚠️ **문제가 발생하면 무조건 F9부터 누르세요.**  
⚠️ 마우스가 이상하게 움직이면 **F9 → 손 떼기** 순서입니다.

---

## 주요 기능

- `/강화` 명령 자동 입력
- 강화 결과 자동 판별
  - 강화 성공 / 유지 / 파괴 / 미상
- 현재 강화 단계 자동 인식 (`[+N]` 기준)
- 사용 골드 / 남은 골드 기록
- **강화 단계별 통계 자동 누적**
  - 성공 / 유지 / 파괴 횟수
  - 단계별 총 사용 골드
- 목표 강화 단계 도달 시 자동 중지
- 단축키(F8 / F9)로 즉시 제어 가능

## 사용 방법

### 1. 실행 전 준비

1. 카카오톡 PC 버전 실행
2. 플레이봇이 있는 채팅방 열기
3. **채팅방을 화면 한쪽에 고정**
4. 채팅방 크기를 플레이봇의 메세지가 다 들어올 만큼 크게 하기

---

### 2. 좌표 설정 (필수)

코드 상단의 좌표를 **본인 환경에 맞게 반드시 수정**해야 합니다.

```python
# 채팅 입력 위치
CHAT_X, CHAT_Y = 200, 960

# 채팅 내용 영역 (대화가 표시되는 영역)
CHATBOX_X1, CHATBOX_Y1 = 10, 100   # 좌상단
CHATBOX_X2, CHATBOX_Y2 = 340, 910  # 우하단
```

좌표 설정 시 주의:
- 채팅 텍스트가 표시되는 영역만 포함
- 스크롤바, 버튼, 프로필 영역 포함 ❌

---

### 3. 실행

```bash
python main.py
```

실행 시 현재 강화 단계와 남은 골드를 자동 인식합니다.

---

## 동작 원리

동작 흐름:

1. `F8` 입력 → 매크로 시작
2. `/강화` 명령 자동 입력
3. 채팅 영역 화면 캡처
4. 채팅 영역의 **화면 변화 감지**
5. 변화 감지 시
   - 마우스로 채팅 영역 자동 드래그
   - `Ctrl + C`로 채팅 내용 클립보드 복사
6. 클립보드 텍스트 분석
   - 강화 성공 / 유지 / 파괴 판별
   - `[+N]` 형식으로 현재 강화 단계 추출
   - 사용 골드 / 남은 골드 추출
7. 통계 업데이트 후 다음 강화 진행
8. `F9` 입력 시 언제든 즉시 중지

---

## 통계 기준

- 강화 성공:
  - `+6 → +7` 성공 시 `+6` 레벨 통계에 기록
- 강화 유지 / 파괴:
  - 현재 레벨 기준으로 기록

## ⚠️ 매우 중요한 경고

**이 프로그램은 키보드와 마우스를 직접 제어합니다.**

반드시 아래 사항을 지키세요:

- 카카오톡 채팅방을 **화면 한쪽에 고정**
- 코드상 채팅 영역을 **카카오톡 UI안에 다 들어갈만큼 설정**
- 마우스 드래그가 **절대 채팅 영역을 벗어나지 않게 설정**
- 실행 중 다른 프로그램 조작 금지

이를 지키지 않으면:
- 엉뚱한 프로그램 클릭
- 잘못된 텍스트 복사
- 원치 않는 명령 입력
- 시스템 오동작

이 발생할 수 있습니다.
**문제 발생 시 무조건 F9부터 누르세요.**
